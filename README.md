# Merriday

Merriday makes one wish image on a Windows PC or laptop.

1. The SpinSci logo is already on every wish. Replace it only if the logo file changes.
2. Add the employee photo and name.
3. Choose birthday, anniversary, or appreciation.
4. Write a short note. The card turns it into a team wish for a birthday, work anniversary, or appreciation.
5. Choose **Copy image**, then paste it with Ctrl+V.

Nothing is uploaded.

## Open it on Windows

1. Install Node.js from [https://nodejs.org](https://nodejs.org) if it is not installed yet.
2. Double-click `Start Merriday.bat`. The first open builds the app once. Later opens start quickly.
3. Leave the black window open. Closing it stops the app.
4. The browser opens at [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Open it on a Mac or Linux laptop

```bash
chmod +x start-merriday.sh
./start-merriday.sh
```

## Assumptions

- The image is a picture, so paste it into a chat, email, or document that accepts images.
- If the browser blocks the copy, right-click the image and choose Copy image.
- The logo stays in this browser. The photo and message stay on the page until you change them.
